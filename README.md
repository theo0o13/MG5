### Activity

1. Basically, NavMesh is good for NPCs that needs to avoid the obstacles, like characters in The Sims game. Physics-based movement suits games that require jumping and falling movements, like Super Mario.

2. The loop goes through all the birds in the list. The Vector3.Distance function gets the distance between each bird and the player. If a bird is within _interactDistance, it will run away.
